# Scam Hunter｜最後一則訊息

聊天式懸疑防詐教育 Web App。

## 發布到 GitHub Pages
1. 解壓縮上傳包。
2. 把 `index.html`、`README.md`、`SPECIFICATION.md` 和 `screenshots/` 上傳到 Repository 根目錄。
3. 到 `Settings → Pages`，選 `Deploy from a branch`、`main`、`/(root)`，按 `Save`。
4. 等部署完成後按 `Visit site`。

重要：請上傳解壓縮後的內容，不要只上傳 ZIP，也不要把整個專案資料夾再包一層。`index.html` 必須直接在 Repository 根目錄。音樂與音效請在遊戲內點擊控制按鈕啟用。
