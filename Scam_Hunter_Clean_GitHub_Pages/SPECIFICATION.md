# Scam Hunter｜最後一則訊息 — 規格書

## 專案概念
本作品是一款以防詐騙教育為主題的聊天式懸疑互動 Web App。玩家在故事中收到求助訊息，透過聊天內容、線索與分支選項判斷資訊是否可信，練習保持冷靜、查證身分並避免危險操作。

## 目標使用者
學生及一般網路使用者，協助認識冒充熟人、假客服、可疑金錢要求與異常聯絡方式等風險。

## 核心功能
1. 聊天式劇情：以訊息泡泡、角色名稱及時間標記呈現故事。
2. 分支選項：不同回應與查證方式影響後續故事。
3. 線索調查：蒐集及查看關鍵線索，幫助辨識異常資訊。
4. 角色立繪與表情：小安、阿哲、神祕聯絡人及假客服，採電影感日系動畫半身立繪。
5. 多重結局：依玩家選擇與調查行動呈現不同結果。
6. 存檔管理：提供瀏覽器本機存檔及可用時的 JSON 備份／匯入；不同瀏覽器對本機檔案的儲存行為可能不同。
7. 音樂與音效：透過瀏覽器 Web Audio API 產生懸疑氛圍音樂及互動提示音，可自行開關。
8. 響應式介面：依不同螢幕寬度調整聊天區、角色區與線索區。
9. 動畫控制：提供動態效果與減少動畫選項。

## 視覺設計
以深藍、黑色與青綠色為主色，營造深夜通訊及懸疑調查氣氛。聊天視窗為主要互動區，角色立繪、線索進度與調查提醒為輔助資訊。

## 技術與 Vibe Coding 流程
使用 HTML、CSS 與 JavaScript，將樣式、互動邏輯及角色圖片整合於單一 `index.html`。開發流程包括與 AI 討論構想、整理規格、建立原型、試玩、修正角色圖片顯示問題，再調整介面、存檔及音訊功能，最後部署到 GitHub Pages。

## 防詐教育目的
讓玩家練習查證聯絡人身分、辨識不合理金錢要求與可疑連結，理解不應因急迫訊息或情緒壓力而貿然轉帳或提供敏感資料。

## 發布方式
GitHub Pages 應從 Repository 根目錄的 `index.html` 發布。
